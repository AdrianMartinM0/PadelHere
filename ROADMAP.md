# Roadmap Oficial de Desarrollo — PadelHere

## Épicas y Funcionalidades de Negocio (Core PadelHere)
Próximas fases de desarrollo funcional para jugadores y clubes:

- [ ] **1. Torneos y Competiciones:** Generación de cuadros clasificatorios, horarios, emparejamientos y registro de resultados.
- [ ] **2. Reservas Recurrentes:** Lógica de reservas fijas semanales para socios y clubes con gestión de excepciones y festivos.
- [ ] **3. Pasarela de Pagos:** Integración con proveedor de cobro (ej. Stripe) para fianzas, reservas directas y cuotas de torneo.
- [ ] **4. Estadísticas y Analíticas:** Dashboard de ocupación de pistas, franjas horarias más demandadas y métricas de ingresos.
- [ ] **5. Roles y Permisos Granulares:** Modelo estricto de autorización (RBAC) para Superadmin, Administrador de Club y Jugador.
